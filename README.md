# llimorse

A Rust crate for LLM agent harnesses.

(Currently only for use with llama.cpp’s llama-server.)

Crates in this workspace:
* llimorse: The central crate ([documentation](https://xanclic.github.io/llimorse/llimorse/index.html))
* llimorse-chat: Helpers for building chatbot-style harnesses ([documentation](https://xanclic.github.io/llimorse/llimorse_chat/index.html))
* term-ui: Terminal interface for such chatbots ([documentation](https://xanclic.github.io/llimorse/term_ui/index.html))
* work-buddy: Example application for managing day-to-day to-do tasks and a log of work done ([documentation](https://xanclic.github.io/llimorse/work_buddy/index.html))
